# Candango Faz Bootstrap

## Introduction

Candango faz-bootstrap is a toolkit based on bootstrap and solid-js.

# Installation

## npm

```
> npm i faz-bootstrap
```

## yarn

```
> yarn add faz-bootstrap
```

# Development

## At the command line

```
> yarn
> npm run sass:dev
> npm run run
```
